Single-omics analysis

Single-omics pipelines

BiomiX provides ready-to-use pipelines for transcriptomics, metabolomics, and methylomics analysis. This page describes the input format requirements, the Preview-QC tool, and each omics pipeline in detail.

General guidelines Preview-QC Transcriptomics Metabolomics Methylomics
📋

General guidelines

BiomiX compares two groups using single and multiple omics. To work correctly, input files must follow a specific format.

Metadata file

A metadata file must be provided. The first column must contain the sample ID, while the remaining columns contain sample variables.

ColumnDescription
ID Mandatory First column. Contains the unique sample identifier.
CONDITION Mandatory Sample condition. These values will be available for group selection in the main interface.
SAMPLE_TYPE Optional For convoluted matrices containing samples from different tissues or cell types. If the tissue/cell type is encoded in the sample ID (e.g., 25658_BLymphocyte), this column allows analysis on a specific subset.
GENDER Optional Used to adjust the Limma or DESeq2 model in transcriptomics analysis.
AGE Optional Used to adjust the Limma or DESeq2 model in transcriptomics analysis.
Any other column Optional Can be used to filter samples via the Metadata section in advanced options, or for PCA and UMAP visualization in Preview-QC.

Expression matrix

BiomiX requires a matrix where columns represent samples and rows represent variables. Accepted formats: .tsv, .xls, .xlsx.

  • Transcriptomics: Variables (genes) must be named using Gene Symbol or Ensembl ID.
  • Metabolomics: Variables (metabolites) should use KEGG, HMDB, or official compound names. For unannotated peaks, use the format peak_[number].
  • Methylomics: Variables must use the EPIC or 450K array probe codes.
  • Undefined omics: Any variable name is accepted.

Directory system and reproducibility

BiomiX follows the FAIR principles (Findability, Accessibility, Interoperability, and Reuse) to ensure reproducible analyses.

  • Save inputs in the correct location: Although BiomiX can read matrices from any location, we strongly recommend saving a copy within the BiomiX shared folder — metadata in the Metadata/ subfolder, and omics matrices in the corresponding omics subfolder.
  • Analysis reports: After each completed analysis, a report file is automatically saved, including the filenames used, the analysis type, and all parameters, to guarantee reproducibility.
🔍

Preview-QC

Selecting Preview-QC in an omics input slot opens a Shiny interface for data exploration and quality control before analysis. It includes four sections:

  • Plot section: Scatter plots of the top 50 high-variance variables, PCA, UMAP, and correlation heatmaps. Data can be transformed using logarithmic transformation, median/mean centralization, Z-score, MAD, quantile, Loess, or variance stabilizing transformation (VST).
  • Data Table section: Preview of the matrix.
  • Outliers section: Filters variables by variance threshold and identifies sample outliers via PCA.
  • Download section: Download the transformed matrix for external use.

Once satisfied with the transformation and QC, press the Close App button to pass the current matrix to the analysis pipeline.

⚠️

For metabolomics, QC samples can be uploaded by labeling them as "QC" in the CONDITION column. They will be visible in the Preview-QC for distribution comparison and can then be excluded from statistical analysis.

🧬

Transcriptomics

The transcriptomics pipeline identifies differentially expressed genes (DEGs) and provides volcano plots and heatmaps. Default thresholds: Log2FC > 0.5 and adjusted p-value < 0.05. If GENDER and AGE columns are present in the metadata, they are used to adjust the DESeq2 or Limma model.

If the data are transformed in Preview-QC, Limma is used for differential expression. If the matrix contains raw counts and no transformation is applied, DESeq2 is used instead. The transformed data are then passed to the integration module.

Biological process enrichment is explored using the R version of EnrichR. BiomiX also prepares export files for GSEA and EnrichR. To optimize speed, only the most variable genes are used as input for integration (5,000 by default, adjustable in the advanced options).

Additional features

Gene panel subgrouping

A gene panel can be provided via the GENE_PANEL file in the General section of advanced options. Genes must be in Gene Symbol format, one per line:

GENES_FOR_SUBPOPULATION
SIGLEC1
IFIT3
IFI6
LY6E
MX1
USP18
OAS3
IFI44L

These genes generate a heatmap showing each gene's expression Z-score across samples, enabling classification of condition samples into positive and negative subgroups. BiomiX then runs DGE analysis comparing controls with each subgroup.

Clinical or biological marker validation

Adding a MARKER column in the metadata allows sample classification based on a clinical or biological marker. This classification can then be compared with gene panel subgrouping to identify similarities or differences.

⚗️

Metabolomics

Peak or metabolite signals are first explored via Preview-QC to decide on data transformation. Transformed signals are then compared between groups: Log2FC is computed as the log2 ratio of median peak signals, and p-values are calculated with the Mann-Whitney test corrected by FDR. Volcano plots and heatmaps display significantly changed metabolites or peaks.

Pathway enrichment is performed using methPath v1.0.5 from TidyMass v1.0.8. BiomiX also prepares ready-to-copy input files for MetaboAnalyst, supporting enrichment and metabolite set enrichment analysis. If transcriptomics results are available, BiomiX automatically prepares joint pathway and network analysis files for MetaboAnalyst.

⚠️

Ensure that the data matrix is curated before upload: remove variables without biological relevance (contaminants, poorly reproducible signals) and perform instrumental normalization beforehand. If you have only raw .mzML files, we recommend using the R pipeline by Á. Fernández-Ochoa or MetaboAnalyst to generate the peak matrix first.

Additional features

Targeted metabolomics

For data from any analytical platform (LC-MS, GC-MS, CE-MS, NMR) where metabolite identities are already available. The correct metabolite identifier (HMDB or KEGG) is required for pathway analysis. The IUPAC compound name is also accepted but will not trigger pathway analysis.

MS1 annotation (untargeted HRMS)

BiomiX uses the CEU Mass Mediator database to match the m/z of unannotated peaks. Default tolerance: 15 ppm for positive mode. Available adducts in positive mode: M+H, M+2H, M+Na, M+NH4, M+H-H2O. In negative mode: M-H, M-Cl, M+FA-H, M-H-H2O. Databases consulted by default: HMDB, LipidMaps, Metlin, KEGG (all customizable).

MS1 and DDA-MS/MS annotation (.mzML and .mgf)

Extends MS1 annotation with fragmentation spectra matching against HMDB, MassBank, and MoNA databases. MS2-based annotations replace MS1 ones where available, due to their higher reliability.

Sample type filtering

BiomiX can filter metabolites using HMDB specimen-specific lists, retaining those identified in the relevant sample type (plasma, urine, saliva, CSF, feces, sweat, breast milk, bile, or amniotic fluid).

🔬

Methylomics

BiomiX performs differential methylation analysis using the ChAMP package. Output includes CpG island delta-beta values, FDR-adjusted p-values, a volcano plot, and a heatmap. Default thresholds: delta-beta > |0.15| and adjusted p-value < 0.05 (FDR).
