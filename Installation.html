Installation

Get BiomiX 3.0 running

BiomiX 3.0 installs through Docker, replacing the previous Conda-based setup. Each analysis module is distributed as an independent container, so you only download what your analysis actually needs.

0

Install Docker

BiomiX 3.0 requires Docker to be installed on your system. We recommend Docker Engine on Linux/Ubuntu, which is the environment BiomiX 3.0 has been built and tested for.

1

Pull the modules you need

biomix_gui and biomix-base are always required — the first provides the BiomiX graphical interface, the second the core R environment used by every analysis module. Add only the single-omics and integration modules relevant to your analysis — each one is an independent container.

Module Pull command Required
biomix_gui
BiomiX graphical interface — Shiny frontend
docker pull ghcr.io/biomix-consortium/biomix_gui:latest

biomix-base

docker pull ghcr.io/biomix-consortium/biomix-base:latest

💡

Example: to run a transcriptomics analysis integrated with MOFA, pull biomix_gui, biomix-base, biomix-transcriptomics, and biomix-mofa — nothing else.

2

Launch BiomiX

Once the modules are pulled, start the BiomiX graphical interface directly from the biomix_gui container. From there, you select your analyses and modules before starting execution. 

# Launch the BiomiX graphical interface
docker run -p 3838:3838 \
  -v /path/to/your/data:/data \
  ghcr.io/biomix-consortium/biomix_gui:latest

Once running, open http://localhost:3838 in your browser. From the interface, you can select the modules to use, configure your analysis, and start execution.

🚧

PRAMIGO will be released as a separate module shortly after BiomiX 3.0. This page will be updated with its pull command as soon as it becomes available.
