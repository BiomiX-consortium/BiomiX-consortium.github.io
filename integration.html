Integration

Multi-omics integration methods

BiomiX 3.0 provides five methodologically diverse integration strategies. Each captures a distinct aspect of multi-omics data — run one or all.

MOFA SNF NEMO DIABLO PRAMIGO Soon

MOFA

Unsupervised Multi-Omics Factor Analysis

A probabilistic Bayesian framework that decomposes multi-omics datasets into latent factors capturing shared and modality-specific sources of variance. In BiomiX 3.0, MOFA is implemented with automated factor selection and semi-supervised discriminant factor identification.

Discriminant factors are interpreted through correlation with clinical data, pathway enrichment via EnrichR, and automated PubMed bibliography search.

Type
Matrix factorization
Best for
Multi-dimensional biological coverage
Output
Latent factors + loadings
Missing data
Supported

SNF

Unsupervised Similarity Network Fusion

A network-based method that constructs a patient similarity network for each omic layer and iteratively fuses them into a single integrated network. The fused network captures complementary cross-modal information. Spectral clustering is then applied to identify patient subgroups.

In BiomiX 3.0, SNF is implemented via the SNFtool R package, with the number of clusters selected automatically via the eigen-gap heuristic.

Type
Network-based
Best for
Patient stratification
Output
Fused similarity network + clusters
Missing data
Not supported

NEMO

Unsupervised NEighborhood-based Multi-Omics clustering

A network-based method specifically designed to handle datasets with partially overlapping samples across omics layers, without requiring imputation. NEMO constructs affinity scores from nearest-neighbor relationships within each omic, using only available modalities per sample.

Type
Network-based
Best for
Partially overlapping samples
Output
Affinity matrix + clusters
Missing data
✓ Natively supported

DIABLO

Supervised Data Integration Analysis for Biomarker discovery using Latent cariable Approaches for Omics

A supervised integration method from the MixOmics framework that extends sparse canonical correlation analysis to multiple omics layers. It identifies correlated latent components across modalities while optimizing discrimination between predefined groups, making it well-suited for biomarker discovery.

In BiomiX 3.0, the number of components is selected automatically via Mann-Whitney test with FDR correction, mirroring MOFA's factor selection strategy.

Type
Sparse CCA
Best for
Biomarker discovery
Output
Latent components + feature weights
Missing data
Excluded before analysis

PRAMIGO Coming Soon

Supervised Phenotyping netwoRk Application for Multi-omics InteGratiOn

A novel supervised Heterogeneous Graph Transformer (HGT) that models cross-modal molecular interactions explicitly. PRAMIGO constructs a heterogeneous graph where nodes represent both samples and molecular features, and edges capture within-omic, between-omic, and sample-feature relationships.

Unlike other methods that summarize variation at the sample level, PRAMIGO uncovers biologically interpretable multi-omics programs and feature-level interactions — including ncRNA hubs, immunoglobulin repertoire diversity, and epigenetic co-regulation programs — that are inaccessible to conventional integration approaches.

Type
Heterogeneous Graph Transformer
Best for
Cross-modal regulatory discovery
Output
Attention scores + multi-omics programs

Which method should I use?

Each method is designed for a different analytical objective. When in doubt, run multiple methods and compare.

DIABLO
Primary goal is biomarker discovery with co-variation across omics layers.
MOFA
Goal is multi-dimensional coverage of independent biological axes without a condition label.
SNF / NEMO
Goal is patient stratification sensitive to sharp between-sample biological boundaries.
PRAMIGO
Goal is cross-modal regulatory mechanism discovery, especially ncRNA, repertoire diversity, or structural cross-modal features. Soon
