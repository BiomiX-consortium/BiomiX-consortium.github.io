Installation

Get BiomiX 3.0 running

BiomiX 3.0 installs via Docker for a clean, dependency-free setup. Legacy conda-based installation is still available for advanced users.

🐳

Recommended: Docker installation

New in 3.0

The Docker approach is recommended for all operating systems. It guarantees a consistent environment and avoids dependency conflicts entirely.

Install Docker Engine, then:

# 1. Pull BiomiX 3.0
docker pull ghcr.io/biomix-consortium/biomix:3.0

# 2. Run with your data directory mounted
docker run -p 8080:8080 \
  -v /path/to/your/data:/data \
  ghcr.io/biomix-consortium/biomix:3.0

BiomiX will be accessible at http://localhost:8080 in your browser.

Install Docker Desktop for Windows, then open PowerShell:

# 1. Pull BiomiX 3.0
docker pull ghcr.io/biomix-consortium/biomix:3.0

# 2. Run with your data directory mounted
docker run -p 8080:8080 `
  -v C:\path\to\your\data:/data `
  ghcr.io/biomix-consortium/biomix:3.0

Install Docker Desktop for Mac (Apple Silicon and Intel supported), then:

# 1. Pull BiomiX 3.0
docker pull ghcr.io/biomix-consortium/biomix:3.0

# 2. Run with your data directory mounted
docker run -p 8080:8080 \
  -v /path/to/your/data:/data \
  ghcr.io/biomix-consortium/biomix:3.0
⚡

Nextflow pipelines

New in 3.0

For HPC clusters or automated workflows, BiomiX 3.0 provides Nextflow pipelines that wrap the Docker container and handle parallelization automatically. 

# Run the BiomiX Nextflow pipeline
nextflow run BiomiX-consortium/BiomiX \
  --input samplesheet.csv \
  --outdir results/ \
  -profile docker

See the GitHub repository for the full Nextflow parameter reference.

Legacy: Conda installation

The conda-based installation from BiomiX v1 is still available for users who prefer it or cannot use Docker. This requires more manual setup. 

# 1. Download and unzip BiomiX
wget https://github.com/BiomiX-consortium/BiomiX/releases/latest/download/BiomiX.zip
unzip -q BiomiX.zip

# 2. Install Miniconda 23.5.0
wget https://repo.anaconda.com/miniconda/Miniconda3-py39_23.5.0-3-Linux-x86_64.sh
bash Miniconda3-py39_23.5.0-3-Linux-x86_64.sh
# Follow prompts and select conda init = yes. Reopen terminal.

# 3. Run the installer
chmod +x _INSTALL/BiomiX_INSTALL_LINUX.sh
./_INSTALL/BiomiX_INSTALL_LINUX.sh

# 4. Launch BiomiX
./Biomix_linux_exe.sh
1. Download BiomiX from:

2. Unzip to your home directory (recommended).

python3 /path/to/BiomiX/_INSTALL/BiomiX_INSTALL_OS.py

Troubleshooting

Common issues and how to fix them.

ModuleNotFoundError: No module named 'package name'

This happens during conda installation when a Python package is missing. Fix it by running:

pip install 'package-name'
Error in library("Package"): No package named "Package"

Open R inside the BiomiX conda environment and install manually:

conda activate BiomiX-env
R  # (or R.exe on Windows)
install.packages("Package")
fontconfig / freetype error on macOS or Linux 
# macOS
brew install freetype

# Ubuntu / Debian
sudo apt-get install libfontconfig1-dev
