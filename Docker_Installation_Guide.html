Step 0 — Prerequisite

Installing Docker

Before pulling and running BiomiX 3.0, you need Docker installed on your system. The installation process differs by platform: Windows and macOS use Docker Desktop (a graphical application), while Linux uses Docker Engine, installed from the command line with no GUI.

🪟 Windows 🍎 macOS 🐧 Linux (Ubuntu) 🛠️ Troubleshooting

Requirements

  • Windows 10 64-bit (build 19045 / 22H2 or newer) or Windows 11 64-bit (build 22631 / 23H2 or newer) — Home, Pro, Enterprise, or Education
  • 64-bit processor with SLAT (Second Level Address Translation)
  • Hardware virtualization enabled in BIOS/UEFI
  • 8 GB RAM recommended (4 GB is the documented minimum, but limited)
  • WSL 2 (Windows Subsystem for Linux) as the backend

Steps

  1. Enable WSL 2 (if not already installed). Open PowerShell as Administrator and run: 
    wsl --install

    Restart your computer when prompted.

  2. Check virtualization

    Make sure hardware virtualization (Intel VT-x or AMD-V) is enabled in the BIOS. On most modern PCs this is already on by default.

  3. Download Docker Desktop

    From the official site: docker.com/products/docker-desktop. Select the build for Windows (x64 or ARM64, depending on your processor).

  4. Run the installer (Docker Desktop Installer.exe)

    Follow the setup wizard. Keep the "Use WSL 2 instead of Hyper-V" option selected when prompted.

  5. Restart your computer if requested at the end of the installation.
  6. Launch Docker Desktop from the Start menu and accept the terms of service on first launch.
  7. Verify the installation by opening a terminal (PowerShell or CMD) and running: 
    docker --version
docker run hello-world

    If you see a welcome message from Docker, the installation succeeded.

Requirements

  • macOS 13 (Ventura), 14 (Sonoma), or 15 (Sequoia) — Docker Desktop supports the three most recent macOS major releases
  • At least 8 GB RAM recommended (4 GB documented minimum)
  • Mac with Apple Silicon (M1/M2/M3/M4) or Intel chip — make sure to download the matching build

Steps

  1. Download Docker Desktop

    From the official site: docker.com/products/docker-desktop. Choose the correct build for your chip — Apple Silicon (M1/M2/M3/M4) or Intel. To check which chip you have: Apple menu → "About This Mac".

  2. Open the downloaded .dmg file

    Drag the Docker icon into the Applications folder.

  3. Launch Docker Desktop from Applications or Launchpad.
  4. Accept the terms of service on first launch.
  5. Grant the required permissions

    Docker Desktop will ask for your system password to install certain privileged components needed for it to run.

  6. (Optional, Apple Silicon) Install Rosetta 2 for compatibility with some command-line tools: 
    softwareupdate --install-rosetta
  7. Verify the installation by opening Terminal and running: 
    docker --version
docker run hello-world
ℹ️ On Linux, Docker Desktop is not needed — you install Docker Engine directly, which is lighter and native (no virtual machine required, unlike Windows/macOS). This is also the environment BiomiX 3.0 is built and tested for.

Requirements

  • Ubuntu 20.04, 22.04, or 24.04 LTS
  • x86_64 or arm64 architecture
  • Linux kernel 3.10 or later
  • Administrator (sudo) privileges

Steps

  1. Remove any older or conflicting versions (optional — skip if you've never installed Docker before): 
    sudo apt-get remove docker docker-engine docker.io containerd runc
  2. Update the package index and install required dependencies 
    sudo apt-get update
sudo apt-get install ca-certificates curl gnupg
  3. Add Docker's official GPG key 
    sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
  4. Add the Docker repository to APT sources 
    echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
  5. Install Docker Engine, the CLI, and plugins 
    sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
  6. Verify the installation 
    sudo docker run hello-world
  7. (Recommended) Run Docker without sudo

    Add your user to the docker group, so you don't need to type sudo before every command:

    sudo usermod -aG docker $USER

    Then log out and back in (or restart your terminal session) for the change to take effect. Verify with docker run hello-world (this time without sudo).

Final check

Once Docker is installed on any platform, confirm everything works with:

docker --version
docker run hello-world

If the command returns a welcome message ("Hello from Docker!"), the installation is complete and you're ready to pull the BiomiX modules.

Common troubleshooting

"Docker won't start" (Windows)

Make sure WSL 2 is installed and up to date (wsl --update) and that virtualization is enabled in the BIOS.

"Cannot connect to the Docker daemon" (Linux)

Make sure the service is running: sudo systemctl start docker, and check its status with sudo systemctl status docker.

Permission denied on Linux

If you skipped the step adding your user to the docker group, you'll need sudo before every Docker command.

Mac with M1/M2/M3/M4 failing to launch some CLI tools

Install Rosetta 2 — see the macOS section above.
