BiomiX 2.4 tutorials v2.4

These tutorials refer to BiomiX v2.4. The interface has changed in version 3.0, but the core analysis workflow and biological logic remain the same.

ℹ️

For a detailed description of all interface parameters, see the Parameters and interface reference page.

1Introduction to BiomiX

An overview of the BiomiX tool and the bioinformatics pipelines used in the analysis. Covers the general structure of the interface, input data requirements, and the main analysis workflow.

2Analysis, data and advanced options

A practical example of BiomiX analysis using transcriptomic data. Covers metadata format, sample selection, advanced options, and results visualization.

3Format conversion, metabolomics, results

How to convert data to the BiomiX format using the assisted format converter. Includes examples of metabolomics analysis with both annotated and unannotated data.

4MOFA integration, results and factor interpretation

A deep dive into MOFA integration within BiomiX, including automatic factor selection, factor interpretation through pathway enrichment, PubMed bibliography search, and clinical correlation analysis.
